# Bandeja de entrada

Acá se deja material nuevo para el sitio: textos o archivos trabajados en ChatGPT,
documentos Word, Markdown, notas o imágenes.

1. Subí el archivo a esta carpeta (desde GitHub: **Add file → Upload files**), o pedile a ChatGPT
   que abra un pull request en este repositorio.
2. En la revisión se lee cada archivo, se corrigen datos y se integra en la página que corresponde,
   con fuentes y en el formato del sitio.
3. Se corren las pruebas y se publica. El archivo original se mueve a `docs/recibidos/` con la fecha.

Si un archivo tiene instrucciones (“poné esto en la página del barrio”), escribilas al principio.
