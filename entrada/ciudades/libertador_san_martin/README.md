# Libertador San Martín, Entre Ríos

Carpeta territorial de referencia para el trabajo de ciudad inteligente.

Los documentos municipales se organizan por áreas y los proyectos residenciales se alojan dentro de `barrios/`, manteniendo la jerarquía **ciudad → barrio → casa**.

## Barrios
- `barrios/la_lomada/`: diseño conceptual de barrio inteligente para La Lomada de Puiggari.

## Criterios
Distinguir siempre entre datos verificados, información publicada por terceros, datos aportados por interesados, hipótesis y pendientes de confirmación.
