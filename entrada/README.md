# LSM Ciudad Inteligente — documentación de entrada

**Fecha:** 4 de noviembre de 2026 · **Estado:** propuesta para revisión e integración.

Esta entrega organiza el proyecto en tres escalas independientes pero interoperables:

1. **Ciudad:** territorio, infraestructura y servicios públicos.
2. **Barrio:** infraestructura y servicios compartidos a escala vecinal.
3. **Casa:** vivienda, instalaciones, dispositivos, IA y robótica doméstica.

Cada escala tiene responsabilidades, inventarios, datos y controles propios. Se comunica con las otras mediante interfaces seguras, autorizadas y revocables. La conectividad entre escalas no debe ser requisito para las funciones esenciales locales.
