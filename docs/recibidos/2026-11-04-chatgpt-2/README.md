# Entrada de documentación

Esta carpeta recibe documentación de trabajo antes de su revisión e integración en el sitio principal.

La organización es jerárquica y obligatoria: **ciudad → barrio → casa**. No colocar aquí documentos sin ubicación territorial definida.

## Estructura
- `ciudades/`: documentación por municipio o ciudad.
- `plantillas/`: estructuras reutilizables para ciudades, barrios y casas.

## Protección de datos
Este repositorio es público. No subir datos personales de residentes, credenciales, planos de seguridad detallados, vulnerabilidades, ubicaciones precisas de cámaras ni documentación confidencial. Para ello se deberá utilizar un repositorio privado autorizado.
