Esta carpeta documenta el modelo de vivienda inteligente y sus implementaciones concretas.

## Documento principal

## Alcance
La casa inteligente debe ser interoperable, segura, eficiente, accesible y capaz de mantener funciones esenciales localmente. La automatización debe adaptarse a las personas y permitir control manual.

Los inventarios de dispositivos y datos privados de cada hogar deben mantenerse separados de los documentos generales de ciudad y barrio.
