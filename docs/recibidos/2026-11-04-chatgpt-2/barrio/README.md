## Alcance
El barrio conecta la planificación de ciudad con la vida cotidiana de sus residentes. Incluye infraestructura, agua, energía, drenaje, conectividad, accesos, espacios comunes, seguridad, mantenimiento, servicios y participación.

Los datos específicos de cada barrio deben mantenerse separados. No se deben extrapolar datos de La Lomada a otros barrios.
