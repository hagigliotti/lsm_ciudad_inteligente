# La Lomada de Puiggari — Barrio inteligente

**Estado del documento:** base conceptual preliminar. No constituye proyecto ejecutivo, memoria de cálculo, especificación de compra ni autorización de obra.

## Contexto inicial
- Ubicación de referencia: Puiggari, Libertador San Martín, Entre Ríos, Argentina.
- Estado informado: desarrollo.
- Figura de aprobación informada: fideicomiso.
- Abastecimiento de agua informado: pozo.
- Conectividad disponible: pendiente de relevamiento.
- Información pública consultada previamente: referencias comerciales a 84 lotes de aproximadamente 1.000 m² y a infraestructura de acceso, calles alumbradas y espacios verdes. Estos datos no sustituyen planos ni certificaciones.

## Objetivo
Preparar el desarrollo para incorporar servicios inteligentes, interoperables y escalables desde el diseño, con IA y robótica como capacidades transversales, sin comprometer seguridad, privacidad ni operación manual.
