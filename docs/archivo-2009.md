# Archivo del proyecto original (julio 2009)

El blog original está en https://lsmciudadinteligente.wordpress.com. No se puede copiar automáticamente
(WordPress.com bloquea a los programas que leen páginas), así que hay que exportarlo a mano. Son dos minutos.

## Exportar desde WordPress (si tenés acceso a la cuenta)

1. Entrá a https://wordpress.com e iniciá sesión con la cuenta del blog.
2. Elegí el sitio **lsmciudadinteligente** → **Herramientas → Exportar** (o *Tools → Export*).
3. **Exportar todo**. Llega un `.zip` por email o se descarga directo.
4. Descomprimilo y subí el archivo `.xml` a esta carpeta como `docs/archivo-2009/lsmciudadinteligente.xml`.
5. Si también querés las imágenes: en la misma pantalla, **Exportar biblioteca de medios**, y subilas a `docs/archivo-2009/medios/`.

## Si no tenés acceso a la cuenta

- Abrí cada entrada en el navegador → **Imprimir → Guardar como PDF** → subí los PDF a `docs/archivo-2009/`.
- O pedí una copia en https://web.archive.org/save (pegá la dirección del blog) para que quede un respaldo público.

## Después

Con el texto original archivado, revisá la sección **“Qué le faltó al proyecto de 2009”** del sitio
y ajustá cada falla según lo que el proyecto realmente proponía (tecnologías, presupuesto, plazos, socios).
